# Module-3-Assignment

## NYC 311 Community Board Clustering

INST414 project analyzing 2025 NYC 311 service request data from NYC Open Data.

The analysis uses K-Means clustering to identify groups of NYC Community Boards based on similarities in the types of quality-of-life complaints reported.

### Main Result

Three clusters of Community Boards were identified:

1. 28 boards — Transportation and parking-oriented complaints
2. 22 boards — Housing and noise-oriented complaints
3. 9 boards — More diverse complaint patterns

### Tools

Python, pandas, NumPy, scikit-learn, matplotlib
